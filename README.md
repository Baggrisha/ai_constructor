# AI Constructor

Начальная реализация редактора для macOS 14+ / Apple Silicon. Модель документа,
транзакции и файловое хранение находятся в платформенно-независимом Rust-ядре;
нативный интерфейс SwiftUI обращается к нему через созданные UniFFI-привязки.

**Статус:** реализация M0 не завершена и пока не прошла приёмочные проверки
T10–T11. Не использовать как единственное хранилище важных проектов.

## Реализовано в исходном коде

- Создание и открытие проекта-папки, поиск, переименование и недавние проекты;
  расположение перемещённого проекта сверяется по идентификатору. Архивация
  переносит запись в раздел «Архив» на этом Mac, не перемещая файлы проекта.
  Дубликат без переписки получает новый идентификатор проекта; история и
  контрольные точки исходного проекта в него не копируются.
- Одна страница с корневым фреймом 1440×900: изменение названия и размеров,
  проверка ревизии и отпечатка, отмена/повтор и сохранение.
- `project.json` и `document.json`, история транзакций, ревизии и
  контрольные точки с контентно-адресуемыми копиями файлов. Восстановление
  точки допускается только если её исходный код и ресурсы не изменились.
- Блокировка записи, журнал с копиями прежних и новых данных, публикация
  манифеста последней и восстановление при следующем открытии. Заменяемые
  файлы атомарно обмениваются с сохранением вытеснённых inode; создание и
  удаление используют атомарное перемещение без перезаписи. При обнаружении
  неоднозначного состояния проект открывается только для чтения; некоторые
  повреждения блокируют открытие. При отсутствии нужных файловых примитивов
  запись завершается ошибкой, без перехода на обычный перезаписывающий rename.
  Проверены отдельные сценарии, а не все возможные отказы и файловые системы.
- Считываемый документ с более новой версией схемы открывается только для
  чтения; манифест должен сохранять обязательные поля текущей версии.

Пустые разделы схемы зарезервированы, но не являются готовыми редакторами.
Распознаваемый документ с не поддерживаемым текущим кодом содержимым открывается
только для чтения; неизвестные поля схемы и некорректный JSON отклоняются без
перезаписи. Никаких функций импорта, генерации, предпросмотра, чата или ИИ
приложение пока не предоставляет.

## Что ещё не сделано для M0

Удаление в Корзину, дублирование проектов с чатами и заменой идентификаторов
переписки, миграции, наблюдение и слияние внешних изменений,
полная модель узлов и операций A.6–A.9, перепривязка ресурсов, асинхронные
отменяемые длительные операции, полное восстановление изменённых исходников и
ресурсов из контрольных точек, обработка всех случаев восстановления и конфликтов.
Файлы `src/generated/` не
синхронизируются с документом: автоматической генерации и разбора AST нет.
Папка проекта может содержать приватную переписку и визуальные образцы;
проверьте их перед публикацией. Git-команды приложение не запускает.

Каждая опубликованная транзакция оставляет журнал, его копии и вытеснённые
файлы в `.aic-local/retained/<transaction-id>/`. Их **не удаляют автоматически**:
сторонний процесс может ещё держать старый файловый дескриптор и записать в
вытеснённый inode после сохранения. Такие поздние изменения приложение не
отслеживает автоматически. Сохранённые варианты занимают место и могут
содержать приватные данные; не удаляйте и не исключайте эту папку из резервной
копии до ручного разрешения конфликтов и подтверждения закрытия внешних
дескрипторов. Внешняя запись может менять сохранённый inode и после проверки
его хеша: он не является неизменяемой резервной копией. Гарантии не покрывают
стороннюю порчу `.aic-local`, враждебные изменения структуры каталогов или
файловые системы, не обеспечивающие обещанную атомарность и долговечность.
Отдельные резервные копии проекта по-прежнему необходимы.

## Зависимости

- macOS 14 или новее, arm64.
- Rust stable 1.97+ и Cargo; зависимости закреплены в `Cargo.lock`.
- Для стеклянных системных материалов при компиляции нужен macOS 26+ SDK.
- Для Xcode-сборки и XCTest нужен полный Xcode с выбранным `xcode-select`.
  Для альтернативной сборки из терминала нужны Apple Command Line Tools,
  содержащие Swift и macOS SDK с SwiftUI/AppKit. Генерация привязок и сборка
  требуют доступ к crates.io при первом запуске; само приложение ничего не
  скачивает. Node пока не нужен: веб-ресурсы и экспорт не реализованы.

Лицензия исходного кода ещё не выбрана; сам по себе публичный доступ к
репозиторию не предоставляет лицензию на использование кода.

## Сборка и запуск

Из корня репозитория:

```sh
# Полный Xcode: Rust, генерация настоящего Swift UniFFI и приложение.
./scripts/build-macos.sh
open build/AIConstructor.app
```

Скрипт не перезаписывает уже существующий `build/AIConstructor.app`; перед
повторной сборкой перенесите старый результат в другое место. Для сборки без
полного Xcode, если выбранные Command Line Tools содержат подходящий SDK:

```sh
./scripts/build-macos-clt.sh
open build/AIConstructor.app
```

Второй сценарий вызывает `swiftc` с `-target arm64-apple-macosx14.0`, SDK
из `xcrun`, сгенерированными Swift-привязками и статической библиотекой Rust.
В Swift 6.4 SDK `@State` может требовать отсутствующий в CLT плагин
`SwiftUIMacros`; интерфейс использует существующий property wrapper
`SwiftUI.State` через локальный тип `StoredState` и не подменяет приложение.
Оба скрипта собирают debug-вариант и не подписывают приложение для
распространения. Xcode-проект: `apps/macos/AIConstructor.xcodeproj`; до
непосредственного запуска схемы из Xcode выполните
`./scripts/generate-bindings.sh`.

## Проверки после реализации

```sh
cargo test --workspace --locked
cargo fmt --all -- --check
cargo clippy --workspace --all-targets --locked -- -D warnings
./scripts/build-macos-clt.sh
# При наличии полного Xcode сохраните предыдущую сборку и продолжайте:
mv build/AIConstructor.app "build/AIConstructor.clt.$(date +%s).app"
./scripts/build-macos.sh
./scripts/smoke-macos.sh
```

Отдельные проверки критических сценариев (SIGKILL проверяется отдельно от
смоделированных ошибок; отключение питания и приёмку они не заменяют):

```sh
cargo test --locked -p aic-core storage::tests -- --test-threads=1
cargo test --locked -p aic-core storage::tests::interruption_at_each_publication_recovers_old_or_new_state -- --exact
cargo test --locked -p aic-core storage::tests::unknown_file_version_during_recovery_is_preserved_and_read_only -- --exact
cargo test --locked -p aic-core storage::tests::unknown_commit_marker_preserves_both_versions_and_opens_read_only -- --exact
cargo test --locked -p aic-core --test project stale_transaction_and_external_edit_do_not_destroy_data -- --exact
cargo test --locked -p aic-core --test project tracked_files_can_be_copied_without_local_cache -- --exact
cargo test --locked -p aic-core --test project checkpoint_restores_document_as_a_new_revision_after_restart -- --exact
```

XCTest запускает приложение с отдельными временными папками для проектов и
Application Support. Дополнительно необходима ручная проверка двух независимых
проектов и полного T10–T11, включая прерывания процесса и внешние изменения;
наличие тестового кода само по себе не подтверждает прохождение приёмки.
